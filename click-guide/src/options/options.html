AI 문장 다듬기 선택

켜면 단계 제목·설명, 동작 종류, 요소 이름과 종류(버튼·입력란 등)가 아래 주소로 전송됩니다. 설명 문장에 입력값이 들어 있으면 그 값도 함께 갑니다. 페이지 주소와 제목은 보내지 않습니다. 사내 정보가 담긴 화면이라면 연동 전에 보안 정책을 확인하세요. 스크린샷은 따로 켜지 않는 한 전송하지 않고, 켜면 편집기에서 가린 부분을 적용한 이미지를 보냅니다.

속도 진단

이 PC와 화면 크기에서 한 번 촬영하는 데 실제로 얼마나 걸리는지 잽니다. 이 창에 일반 웹페이지 탭이 하나 있어야 합니다. 재는 동안 가장 최근에 본 웹페이지 탭으로 잠시 바뀌었다가 이 화면으로 돌아옵니다.

녹화한 가이드와 스크린샷은 이 브라우저 안에만 저장됩니다. 외부로 전송되지 않습니다.

다른 PC·다른 폴더로 옮기거나 확장 ID 가 바뀌는 업데이트를 하기 전에는 전체 백업을 받아 두세요. 백업(ZIP)에는 가이드·단계·스크린샷 원본과 설정이 들어가고, AI API 키는 들어가지 않습니다. 가져올 때 이미 있는 가이드는 건너뜁니다.

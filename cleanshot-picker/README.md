# CleanShot Picker

웹페이지를 **클릭으로 정리한 뒤** 현재 보이는 화면을 PNG로 저장하는 Chrome 확장입니다.
지우기 · 이동 · 크기 · 텍스트 · 가리기 다섯 도구가 있고, 저장이 끝나면 건드린 것은 전부 원래대로 돌아옵니다.

원본 DOM 구조는 건드리지 않습니다. 모든 변경은 인라인 스타일 한 줄이거나 오버레이 위의 박스라서
`Esc` 한 번이면 페이지가 손상 없이 복구됩니다.

## 설치

1. `cleanshot-picker.zip` 을 압축 해제합니다. 푸는 위치는 상관없지만 **나중에 지우지 않을 곳**에 두세요. 크롬이 이 폴더를 계속 참조합니다.
2. Chrome 주소창에 `chrome://extensions` 를 입력해 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드**를 누르고 `manifest.json` 이 들어 있는 `cleanshot-picker` 폴더를 선택합니다. 파일이 아니라 폴더를 골라야 합니다.
5. 툴바 퍼즐 아이콘에서 핀으로 고정해 두면 편합니다.

설치 직후에는 **이미 열려 있던 탭을 한 번 새로고침**해야 합니다.

## 도구

| 도구 | 키 | 조작 | 하는 일 |
| --- | --- | --- | --- |
| 지우기 | `1` | 클릭 | 요소를 숨깁니다 |
| 이동 | `2` | 드래그, 방향키 | 요소를 옮깁니다 (`transform`) |
| 크기 | `3` | 8방향 핸들 드래그, 방향키 | 너비·높이를 바꿉니다 |
| 텍스트 | `4` | 클릭 후 입력 | 문구를 제자리에서 고쳐 씁니다 |
| 가리기 | `5` | 클릭 / Shift+드래그 | 검은 박스로 덮습니다 |

## 키

| 키 | 하는 일 |
| --- | --- |
| `Alt+Shift+S` | 선택 모드 켜기 / 끄기 (툴바 아이콘과 같음) |
| `1` – `5` | 도구 전환 |
| `↑` `↓` | 지우기·텍스트·가리기에서는 선택 범위, 이동·크기에서는 1px 조정 |
| `←` `→` | 이동·크기에서 1px 조정 |
| `Shift` + 방향키 | 10px씩 |
| `Ctrl+Z` (`⌘Z`) | 종류와 상관없이 마지막 작업 하나 취소 |
| `Enter` | 캡처해서 저장 |
| `Tab` | 툴바를 위/아래로 |
| `Esc` | 편집 중이면 편집만 종료, 아니면 전체 복원 후 나가기 |

파일은 다운로드 폴더 아래 `cleanshot/도메인-날짜-시간.png` 로 저장됩니다.

## 알아두면 좋은 것

**빈자리 남김 / 빈자리 제거** — 툴바 첫 버튼입니다. 기본은 `visibility: hidden` 이라 요소가 차지하던 공간이 남고 주변이 흔들리지 않습니다. 배너처럼 빈칸이 어색하면 **빈자리 제거**(`display: none`)로 바꾸세요. `position` 이 `fixed`·`sticky`·`absolute` 인 요소는 어차피 문서 흐름 밖이라 설정과 무관하게 항상 공간까지 제거합니다.

**툴바가 가리는 요소** — 툴바는 화면 아래 가운데에 있어 쿠키 배너 자리와 겹칩니다. `Tab` 으로 위로 옮기세요.

**가리기** — 요소를 클릭하면 그 요소만큼, `Shift+드래그` 하면 임의 영역을 불투명한 검은 박스로 덮습니다. 마스크는 문서 좌표로 저장되므로 스크롤해도 제자리에 붙어 있습니다.

방식은 검정 하나뿐입니다. 고를 것이 없는 편이 안전하기 때문입니다. 모자이크나 블러는 원본 픽셀을 완전히 버리지 않아서, 계좌번호처럼 되살아나면 곤란한 것을 가릴 때 쓰면 위험합니다. 검은 박스는 그 자리의 픽셀을 통째로 덮어쓰므로 저장된 PNG에 원본이 남지 않습니다.

**크기 조절이 안 먹을 때** — flex·grid 자식은 부모의 규칙이 이기므로 `flex: 0 0 auto` / `grid-area: auto` 를 자동으로 같이 겁니다. 그래도 안 되면 `↑` 로 부모를 잡아 조절해 보세요.

**켜고 찍는 속도** — 아이콘을 눌러 툴바가 뜨기까지 같은 탭에서 두 번째부터는 15~25ms입니다. `Enter` 를 누르고 저장될 때까지는 60~90ms입니다.

크롬은 MV3 확장의 백그라운드 워커를 30초쯤 놀면 종료하는데, 그러면 아이콘을 눌렀을 때 워커가 다시 뜨기를 기다리느라 툴바가 늦게 나타납니다. 이 확장은 30초짜리 알람으로 워커를 계속 깨워 둬서 첫 클릭도 기다림 없이 뜹니다. 대가는 확장을 쓰지 않는 동안에도 30초마다 워커가 잠깐 깨어난다는 것입니다(한 번에 수 밀리초). 선택 모드가 열려 있는 동안과 닫은 뒤 5분간은 페이지 쪽에서도 20초마다 워커를 깨워 둡니다.

## 권한

| 권한 | 용도 |
| --- | --- |
| `activeTab` | 아이콘을 누른 그 탭에서만, 그 순간만 캡처와 스크립트 주입을 허용 |
| `scripting` | 선택 모드 진입 시 피커를 주입 |
| `downloads` | PNG 저장 |
| `storage` | 숨김 방식과 툴바 위치 보관 |
| `alarms` | 백그라운드 워커를 깨워 두기 (설치 경고 문구 없음) |

`<all_urls>` 는 요청하지 않습니다. 설치할 때 "방문하는 모든 웹사이트의 데이터를 읽고 변경" 경고가 뜨지 않습니다.

## 알려진 제약

- **cross-origin iframe** 안의 개별 요소는 집을 수 없습니다. iframe 전체를 통째로 지우세요. 광고는 대부분 이걸로 해결됩니다.
- **closed shadow DOM** 안도 마찬가지로 호스트 요소 단위로만 다뤄집니다.
- `chrome://`, 웹스토어, 다른 확장 페이지에는 주입할 수 없습니다. 아이콘에 `✕` 배지가 잠깐 뜹니다.
- 저장되는 이미지는 CSS 픽셀이 아니라 **장치 픽셀** 크기입니다. 고해상도 화면에서는 눈에 보이는 것보다 큰 이미지가 나옵니다.
- 텍스트 편집은 React 같은 프레임워크가 리렌더하면 되돌아갈 수 있습니다. 대개 캡처는 몇 초 안에 끝나므로 실제 문제가 되는 일은 드뭅니다.

## 파일 구성

```
cleanshot-picker/
├── manifest.json     권한과 진입점 선언 (MV3)
├── background.js     service worker — 주입, 캡처, 저장
├── picker.js         content script — 오버레이, 다섯 도구, 작업 스택
├── icons/            16 / 32 / 48 / 128 px
└── README.md
```

`picker.js` 의 오버레이는 shadow DOM 안에서 **마스크 레이어**와 **UI 레이어**로 나뉩니다.
캡처 직전 `.capturing` 클래스로 UI 레이어만 숨기므로 가리기 박스는 사진에 남고 툴바는 빠집니다.

되돌리기는 종류별 목록이 아니라 **하나의 작업 스택**입니다. 각 작업이 자기 복원 함수를 들고 있어
`Ctrl+Z` 는 무엇이 마지막이었는지 몰라도 되고, 전체 복원은 스택을 비우는 것과 같습니다.

## 검증

실제 Chromium에 확장을 로드해 54개 항목(기능 38 + 가리기 11 + 워커 깨우기 5)을 통과시켰습니다.

- 지우기: 고정 요소 `display:none` / 흐름 안 `visibility:hidden` 분기, 레이아웃 시프트 없음, 링크 클릭 차단
- 이동: 드래그 이동이 `transform` 으로 적용, 방향키 1px, 연속 방향키가 한 작업으로 묶임, 단계별 되돌리기
- 크기: 핸들 8개 표시, 드래그한 만큼 정확히 변경, flex 자식 `flex: 0 0 auto` 보정, 되돌리기
- 텍스트: `plaintext-only` 진입과 포커스, 타이핑 반영, `Esc` 로 편집만 종료, 원문 복원
- 가리기: 요소 마스크와 영역 마스크가 모두 순수 검정, 방식 전환 버튼이 없음, 대기 없이 19ms 만에 그려짐, 되돌리기, 마스크가 masks 레이어에 있고 `.capturing` 에서도 살아남음, 예전 판이 남긴 설정 키가 치워지고 쓰던 설정은 보존
- 캡처: PNG 저장, 캡처 후 전체 복원과 종료, 재주입 토글, 전체 캡처 버튼과 `Shift+Enter` 가 남아 있지 않음
- 속도: 30초 예열 알람이 등록되고 실제로 워커를 깨우는지, 선택 모드가 열려 있는 동안과 닫은 뒤에도 페이지가 워커를 깨우는지, 예열 중에도 선택 모드가 정상인지, 확장 UI를 숨긴 프레임이 합성된 뒤에 찍히는지(툴바가 사진에 새지 않는지)를 3회 반복 확인

결과 이미지도 눈으로 확인했습니다. 가린 계좌번호 줄은 저장된 PNG에서 **색이 한 종류(`#000`)뿐**이라
원본 픽셀이 남아 있지 않고, 툴바는 사진에 새지 않습니다.

> 이미 이 확장을 쓰고 있었다면 새 폴더로 갈아 끼우기만 하면 됩니다. 예전 판이 저장한 가리기 방식
> 설정은 첫 실행 때 알아서 지워지고, 빈자리 설정과 툴바 위치는 그대로 유지됩니다.

# Jira 주간보고 생성기 (크롬 익스텐션)

툴바 버튼 → **이번 주 보고서 만들기** 를 누르면, 오늘 날짜가 속한 주(월~일)의 SAN 작업과 스프린트 진척률을 모아
정해진 주간보고 양식으로 정리합니다.

**이번 주 작업 선정 규칙**
1. 작업시작일(시작일(Start))이 이번 주면 포함
2. 아니면 종료일(종료일(Finish))이 이번 주인지 확인해 포함
3. 둘 다 아니면 이번 주에 진행률(%)이 바뀐 작업인지 확인해 포함

목록은 작업시작일 순으로 정리됩니다. `1) 기능 개발`(`{{내작업목록_키}}`)에는 **내가 담당인 작업만** 들어갑니다. 결과는 팝업에서 바로 고친 뒤 **복사하기**로 붙여넣으면 됩니다.

데이터는 브라우저와 Jira 사이에서만 오가며, 다른 서버로 보내지 않습니다.

## 설치 (1분)

1. 압축을 풀어 `jira-weekly-report` 폴더를 지워지지 않을 곳에 둡니다. (예: `문서\크롬확장\jira-weekly-report`)
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → 위 폴더 선택
5. 퍼즐 아이콘(🧩)에서 **Jira 주간보고 생성기** 옆 핀을 눌러 툴바에 고정

> 폴더를 옮기거나 지우면 익스텐션도 사라집니다. 새 버전은 폴더를 덮어쓴 뒤 `chrome://extensions`에서 ↻(새로고침)을 누르세요.

## 처음 한 번 설정

팝업의 **⚙ 설정** 을 엽니다.

0. **스페이스/보드** — 기본값은 통합정산시스템 스페이스(**SAN**)의 **보드 281**입니다. 다른 보드를 쓰려면
   Jira 보드 화면 주소(예: `…/jira/software/c/projects/SAN/boards/281`)를 **보드 주소로 채우기** 칸에 붙여넣으세요.
   다른 스페이스의 이슈는 섞이지 않습니다.
1. **연결 테스트** — 크롬에서 raoncorp Jira에 로그인되어 있으면 "연결됨: 이름"이 표시됩니다.
   (회사 정책으로 안 되면 인증 방식을 **API 토큰**으로 바꾸세요.)
2. **진척률** — SAN 스페이스의 **진행률(%)** 필드(customfield_10057)를 쓰도록 이미 맞춰져 있습니다.
   ("개발완료" 상태도 이 필드 값 그대로 반영됩니다.)
3. **보고서 양식** — 보내주신 양식이 기본으로 들어가 있습니다. ✨ 서비스 목록, ✔️ 배포 내역처럼
   고정 문구는 여기서 고치면 계속 유지됩니다. **현재 설정으로 미리보기**로 바로 확인할 수 있습니다.
4. **저장**

## 양식 작성 규칙

- `{{스프린트번호}}`, `{{스프린트실적}}` 처럼 `{{ }}` 안의 항목이 자동으로 채워집니다.
- `   - {{작업목록}}` 처럼 **목록 항목이 들어간 줄은 이슈 수만큼 반복**됩니다. 이슈가 없으면 `   -` 만 남습니다.
- `{{작업목록_키}}` 처럼 `_키`를 붙이면 `[SAN-986] 제목` 형식으로 나옵니다.
- 한 줄 형식(`{요약}{진척}` 등)은 설정에서 바꿀 수 있습니다. 전체 항목은 설정 화면의 "양식에 쓸 수 있는 항목"을 보세요.

| 목록 | 내용 |
|---|---|
| `{{작업목록}}` | 이번 주 작업 중 버그 제외 (작업시작일 순) |
| `{{버그목록}}` | 버그 유형 이슈 |
| `{{지연목록}}` | 종료예정일이 지났는데 완료·100%가 아닌 이슈 (이번 주 작업 + 현재 스프린트) |
| `{{완료목록}}` | 이번 주에 완료된 이슈 |
| `{{진행목록}}` / `{{예정목록}}` | 진행 중 / 해야 할 일 |
| `{{내작업목록}}` 등 | 목록 이름 앞에 `내`를 붙이면 내가 담당인 것만 (`{{내작업목록_키}}`, `{{내버그목록}}` …) |

## 진척률은 이렇게 계산합니다

- **이슈 옆 `(90% -> 100%)`**: 이번 주 월요일 0시 시점의 값 → 지금 값. Jira 변경 이력을 되돌려 계산하므로
  처음 쓰는 주부터 표시됩니다. 값이 그대로면 `(80%)`, 0%·100%로 변화가 없으면 표시하지 않습니다.
- **스프린트 실적**: 현재 스프린트 **전체** 이슈의 진행률(%) 평균 (설정에서 *완료 이슈 비율*, *스토리 포인트 가중*으로 변경 가능)
- **이전 진척률** (`{{지난주실적}}`): 현재 스프린트의 **이번 주 월요일 0시 시점** 진척률 = 지난주 보고 값
- `{{이전스프린트실적}}`: 직전 스프린트가 종료된 시점의 진척률 (필요하면 양식에 넣어 쓰세요)
- **전체 진척률** (`{{전체실적}}`): 기본은 비어 있어 `-`로 나옵니다. 기준이 정해지면 설정의 "전체 진척률 JQL"에 범위를 적으세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| "Jira에 로그인되어 있지 않습니다" | 버튼을 눌러 Jira 로그인 후 다시 만들기 |
| 로그인했는데도 401 | 설정 → 인증 방식 **API 토큰** 사용 |
| "진행 중인 스프린트가 없어…" | 설정 → 보드를 직접 선택하거나 "스프린트 없을 때 JQL" 조정 |
| 이슈가 너무 많거나 적음 | 설정 → 기본 JQL / "내가 담당한 이슈만" / 하위 작업 포함 여부 |
| 결과가 이상함 | 팝업의 **Jira에서 확인**으로 실제 사용된 JQL 결과를 열어 비교 |

Jira 연결

기본은 크롬에 로그인된 Jira 세션을 그대로 사용합니다. 사내 보안 정책으로 안 되면 API 토큰을 쓰세요.

Jira 보드 화면의 주소를 붙여넣으면 아래 Jira 주소 · 스페이스 키 · 보드가 자동으로 채워집니다.
이슈 키 앞부분 (SAN-986 → SAN). 이 스페이스의 이슈만 가져옵니다.
여기서 발급합니다. 토큰은 이 PC의 크롬에만 저장됩니다.

이번 주 작업 선정

① 작업시작일이 이번 주(월~일)면 포함 → ② 아니면 종료일이 이번 주인지 확인 → ③ 아니면 이번 주에 진행률이 바뀌었는지 확인합니다. 목록은 작업시작일 순으로 정리됩니다. 양식에서 {{내작업목록_키}}처럼 "내"를 붙이면 내가 담당인 작업만 나옵니다.

작업시작일이 이번 주가 아닐 때 이 날짜로 확인합니다.
이 날짜가 지났는데 완료·100%가 아니면 {{지연목록}}에 들어갑니다.

스프린트 · 이슈 범위

스프린트 실적은 기준일이 포함된 스프린트(없으면 진행 중인 스프린트)의 전체 이슈로 계산합니다.

이번 주 작업을 찾을 범위. 날짜 조건 · 하위 작업 제외 · 내 이슈만 · 정렬은 자동으로 붙습니다.
{{스프린트실적}} · {{지난주실적}} · {{이전스프린트실적}} 계산 범위.
작업 검색 범위 JQL에 {{스프린트ID}}를 넣었는데 기준일에 스프린트가 없을 때만 사용합니다.
{{전체실적}} 계산 범위. 비워두면 계산하지 않고 "-"로 표시합니다. (예: project = {{프로젝트}} AND sprint is not EMPTY)
쉼표로 구분. 이 유형은 {{버그목록}}으로, 나머지는 {{작업목록}}으로 갑니다.
JQL에 쓸 수 있는 항목

진척률

각 이슈 옆의 "(90% -> 100%)" 표시와 스프린트 실적 % 를 어떻게 계산할지 정합니다.

숫자(0~100) 또는 "80%" 같은 값이 들어 있는 필드를 고르세요.
선택 사항. 한 줄에 "상태 이름=퍼센트". 진척률 필드가 비어 있는 이슈에도 적용됩니다.
Jira 변경 이력으로 기준 시점의 값을 되돌려 계산하므로, 처음 쓰는 주부터 "(이전 -> 현재)"가 표시됩니다.
직전 스프린트 실적은 그 스프린트가 끝난 시점의 상태로 계산합니다.

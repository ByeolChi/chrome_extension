# Microsoft Edge에서 사용하기 (망분리 PC)

Chrome을 설치할 수 없는 PC(망분리 PC, 회사 PC 등)에서는 Windows 10/11에 기본으로 들어 있는 **Microsoft Edge**로 Ssoda를 그대로 사용할 수 있습니다.

- Ssoda는 Chromium 표준 확장 프로그램(Manifest V3)이라 Edge에서도 같은 기능이 모두 동작합니다.
- 외부 CDN이나 인터넷 연결 없이 폴더 안의 파일만으로 동작합니다. 인터넷이 차단된 환경에서도 문제없습니다.
- cURL 실행 도우미도 설치할 때 Edge에 함께 등록됩니다.

> [README로 돌아가기](README.md)

## 1. 준비

1. **Edge 버전 확인**: 주소창에 `edge://settings/help` 를 입력합니다. 버전이 **116 이상**이어야 합니다.
2. **파일 옮기기**: 인터넷 PC에서 `ssoda` 폴더(또는 `ssoda.zip`)를 망연계 시스템이나 승인된 USB로 망분리 PC에 옮깁니다.
3. **압축 풀기**: 지우거나 옮기지 않을 고정된 위치에 압축을 풉니다. 예: `C:\Tools\ssoda`
   - 폴더를 열었을 때 `manifest.json` 이 바로 보여야 합니다.
   - 폴더를 지우면 확장 프로그램이 사라집니다.
   - 새 버전이 나오면 같은 폴더에 덮어쓰고 `edge://extensions` 에서 새로고침(⟳)을 누르세요. 확장 ID(`cnnlkogkbglbbbcefpaknbmebieabijo`)가 고정되어 있어 데이터와 도우미가 그대로 유지됩니다.

## 2. 확장 프로그램 로드

1. Edge 주소창에 `edge://extensions` 를 입력합니다.
2. 왼쪽 메뉴(창이 좁으면 화면 아래쪽)에서 **개발자 모드**를 켭니다.
3. 위쪽에 나타난 **압축 풀린 확장 로드** 를 누릅니다.
4. 압축을 푼 `ssoda` 폴더를 선택합니다.
5. 툴바의 **퍼즐(확장) 아이콘** → Ssoda 옆 **눈 아이콘(도구 모음에 표시)** 을 눌러 고정합니다.
6. 아이콘을 클릭하거나 **Alt + Shift + U** 를 누르면 Ssoda 탭이 열립니다.

> Edge를 시작할 때 "개발자 모드 확장 사용 안 함" 같은 안내가 뜰 수 있습니다. **닫기**를 누르면 계속 사용할 수 있습니다. **사용 안 함**을 누르면 `edge://extensions` 에서 Ssoda를 다시 켜야 합니다.

## 3. cURL 실행 도우미 설치 (선택)

PC의 실제 `curl.exe` 로 요청을 실행하려면 도우미를 한 번 설치합니다. 브라우저 전송만 쓸 거라면 건너뛰어도 됩니다.

1. Ssoda의 **cURL 탭 → 설치하기**, 또는 **Send ▾ → cURL 실행 도우미 설정** 에서 **설치 파일 다운로드** 를 누릅니다.
2. Edge가 다운로드를 막으면 다운로드 목록에서 **… → 유지** 를 누릅니다. "일반적으로 다운로드되지 않음" 안내가 나오면 **자세히 표시 → 그래도 유지** 를 누릅니다.
3. 받은 `ssoda-helper-install.bat` 을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누릅니다.
   - 관리자 권한은 필요 없습니다.
   - 등록 위치: `HKCU\Software\Microsoft\Edge\NativeMessagingHosts\com.ssoda.runner`
4. 도우미 창에서 **연결 확인** 을 누릅니다.

> 운영·개발 서버에 SSH로 접속해서 호출하려면 이 도우미가 필요합니다. 설정 방법은 README의 [SSH 터널로 운영·개발 서버에서 호출](README.md#ssh-터널로-운영개발-서버에서-호출-v13)을 보세요. 망분리 PC에서 서버 SSH 포트(기본 22)로 접속이 허용되어 있어야 합니다.

## 4. 데이터 옮기기

컬렉션·환경·히스토리는 브라우저마다 따로 저장됩니다. 다른 PC나 Chrome에서 쓰던 데이터를 가져오려면 다음과 같이 합니다.

1. 기존 PC에서 **설정 → 전체 백업 내보내기** 로 백업 파일을 만듭니다.
2. 백업 파일을 망분리 PC로 옮깁니다.
3. Edge의 Ssoda에서 **설정 → 백업에서 복원** 을 누릅니다.
   - SSH 비밀번호는 저장하지 않으므로 백업에도 없습니다. 보낼 때 입력하면 됩니다.
   - curl 실행 파일 경로 설정은 백업에서 가져오지 않습니다.

## 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| **개발자 모드** 스위치가 없거나 회색으로 잠겨 있음 | 회사 그룹 정책으로 막힌 상태입니다. `edge://policy` 에서 `ExtensionInstallBlocklist`, `ExtensionInstallAllowlist`, `DeveloperToolsAvailability` 등을 확인하고, IT 담당자에게 확장 프로그램 허용을 요청하세요. |
| 로드할 때 "매니페스트 파일이 없거나 읽을 수 없음" | 폴더를 한 단계 잘못 선택한 경우입니다. `manifest.json` 이 바로 들어 있는 폴더를 선택하세요. |
| 로드할 때 최소 버전(minimum_chrome_version) 오류 | Edge가 너무 오래된 버전입니다. IT 담당자에게 Edge 업데이트를 요청하세요. |
| `.bat` 실행 시 "SmartScreen에 연결할 수 없음 … 인터넷 연결을 확인하세요" | 인터넷이 없어 SmartScreen이 파일 평판을 확인하지 못한 것입니다. 창의 **실행**(없으면 **추가 정보 → 실행**)을 누르세요. 실행 버튼이 없으면 파일 **속성 → 일반 → 차단 해제** 를 체크한 뒤 다시 실행하거나, 명령 프롬프트에서 `cd /d %USERPROFILE%\Downloads` 후 `ssoda-helper-install.bat` 로 실행하세요. |
| 도우미 **연결 확인** 실패 | `edge://extensions` 에서 Ssoda의 ID가 `cnnlkogkbglbbbcefpaknbmebieabijo` 인지 확인하세요. 다르다면 예전 버전이 로드된 것이니 새 버전 폴더를 다시 로드하고, 설치 파일을 다시 받아 실행하세요. PowerShell 실행이 정책으로 막혀 있으면 도우미를 쓸 수 없습니다. 이때는 **브라우저로 보내기** 로 사용하세요. |
| 쿠키 가져오기에 로그인 쿠키가 안 보임 | Edge에 저장된 쿠키만 가져옵니다. 해당 사이트에 Edge로 로그인했는지 확인하세요. |

> **Naver Whale** 이 설치된 PC라면 Whale에서도 같은 방법으로 설치할 수 있습니다 (`whale://extensions`).
